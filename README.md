# 📝 To-Do List Project in Python

## 📌 Overview
This **To-Do List** project is a simple **task management system** built using **Python**. It allows users to:
- **Add tasks** with descriptions and completion status.
- **View all tasks** in a structured format.
- **Update existing tasks** (change task details, completion status, etc.).
- **Delete tasks** when they are no longer needed.

## 🚀 Features
✅ **User-friendly menu-based system**  
✅ **Uses Python dictionaries** for efficient task storage  
✅ **Supports task updates and deletions**  
✅ **Demonstrates Python concepts: loops, functions, conditionals**  
✅ **Utilizes inbuilt dictionary functions (`update()`, `setdefault()`, `pop()`)**  

## 🛠️ Technologies & Concepts Used
- **Python** (Beginner-friendly)
- **Dictionaries** (Storing task data)
- **Functions** (For modular code)
- **Inbuilt Functions** (`setdefault()`, `update()`, `pop()`)
- **Conditionals (`if-else`)**
- **Loops (`while` & `for`)**

## 📌 How to Use
1️⃣ **Run the script**  
2️⃣ Choose an option:  
   - `1` → Add a new task  
   - `2` → View all tasks  
   - `3` → Delete a task  
   - `4` → Update a task  
3️⃣ Enter task details as prompted.  
4️⃣ When done, type `N` when asked to continue.
